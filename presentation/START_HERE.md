## Before you record

1. Replace **A, B, and C** with your names: on the title slide, in the orange "Presenter" tag on each slide, and in the notes.
2. Each person learns one code slide: **A** reads input files (slide 3), **B** runs the rule (slide 4), **C** checks plans (slide 6). Each code slide shows only 3 real lines of code, with an orange plain-English line under each one. Point at the code and read the orange line.
3. Run both demo commands once on the computer you'll record on, from the `om522-vrptw` folder:
   ```
   pixi run prototype-demo
   pixi run prototype-demo --checks-only
   ```
4. Rehearse with a timer. The limit is 10 minutes.

For commands, timing, and the instructor's checklist, see [../docs/PROTOTYPE_GUIDE.md](../docs/PROTOTYPE_GUIDE.md).
