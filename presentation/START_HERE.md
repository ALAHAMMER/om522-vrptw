# Prototype presentation: start here

**Use `Prototype_Video_Plan.docx`.** It has the to-do list, the walkthrough, and the script for
all three members (A, B, and C). The video is one web page with buttons, so nobody types commands
or switches windows on camera.

## Open the video page

From the `om522-vrptw` folder:

```
pixi install
pixi run video
```

The page opens in your browser (`notebooks/prototype_video.py`). Leave the terminal open while you
use it, press F5 to clear the results before each take, and press Ctrl + C in the terminal to stop.
